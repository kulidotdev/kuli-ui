---

kuli/ui uses a **copy-paste via shadcn CLI** approach — components are copied directly into your project rather than installed as an npm package. This gives you full control over every line of code.

## Prerequisites

Make sure your project already has:

- React 18+ (React 19 recommended)
- Tailwind CSS v4
- shadcn/ui configured ([shadcn installation guide](https://ui.shadcn.com/docs/installation))
- TypeScript

## Adding Components via CLI

You **MUST** set up the **Kuli Registry** as a namespace in your `components.json` file. This is required because our components rely on this namespace to correctly resolve internal dependencies (such as `@kuli-ui/alert-error`).

Open your `components.json` and add the `"registries"` field (if it doesn't exist):

```json title="components.json"
{
  // Add this section:
  "registries": {
    "@kuli-ui": "https://ui.kuli.dev/r/{name}"
  }
}
```

### Installation

<Callout type="warn" title="Important">
  **Always use `shadcn@latest`** when adding components. Our custom registry depends on the modern dependency resolution architecture introduced in recent versions of the CLI.
</Callout>

Once the namespace is configured, you can add components directly using the `@kuli-ui` prefix:

```bash tab="pnpm"
pnpm dlx shadcn@latest add @kuli-ui/auth-signin
```

```bash tab="npm"
npx shadcn@latest add @kuli-ui/auth-signin
```

```bash tab="bun"
bunx shadcn@latest add @kuli-ui/auth-signin
```

The CLI will automatically fetch the component from the Kuli Registry, resolve all its dependencies (including official shadcn components like `button`), and place the files into your project.
