## Props

### `<TwoFactor>` (Root Provider)

| Prop | Type | Default | Description |
|---|---|---|---|
| `onSubmit` | `(method: TwoFactorMethod, values: TwoFactorValues) => Promise<void>` | `async () => {}` | Verification callback |
| `twofactorMethods` | `TwoFactorMethod[]` | `["totp", "otp"]` | Available methods |
| `currentView` | `TwoFactorMethod` | `"totp"` | Method active on first render |
| `onResendOtp` | `() => Promise<void>` | — | Resend OTP callback. Required when `"otp"` is in `twofactorMethods` |
| `isLoading` | `boolean` | `false` | Disables all inputs |
| `isResending` | `boolean` | `false` | Loading state specific to the resend button |
| `apiError` | `{ message: string; code?: string } \| null` | `null` | Server error to display |
| `totpLength` | `number` | `6` | Number of digits for TOTP |
| `otpLength` | `number` | `6` | Number of digits for email OTP |
| `resendCooldown` | `number` | `60` | Cooldown in seconds after resending OTP |
| `trustDeviceDescription` | `string` | — | Description for the "Trust device" checkbox. Hidden when not provided |
| `children` | `ReactNode` | — | **Required.** |

### `<TwoFactor.Header>`

Automatically changes title and description based on `activeView`:

| `activeView` | Default Title | Default Description |
|---|---|---|
| `"totp"` | `"Authenticator App"` | "Enter the N-digit code from your authenticator app." |
| `"otp"` | `"Email Verification"` | "Enter the N-digit code sent to your email address." |
| `"backup_code"` | `"Backup Code"` | "Enter one of your emergency backup codes." |

### `<TwoFactor.TrustDevice>`

"Trust this device" checkbox. Only rendered when `trustDeviceDescription` is set on the root.

### `<TwoFactor.ResendOtp>`

Only rendered when `activeView === "otp"`. Shows a "Resend" button with a countdown timer.

### `<TwoFactor.AlternativeMethods>`

Rendered inside `<TwoFactor.Footer>`. Displays ghost buttons for every method not currently active.

## Types

```ts
type TwoFactorMethod = "totp" | "otp" | "backup_code";

type TwoFactorValues = {
  method: TwoFactorMethod;
  code: string;
  trustDevice?: boolean;
};
```

## Validation

The schema is built **dynamically** based on `activeView`:

| Method | `code` validation |
|---|---|
| `"totp"` | Exactly `totpLength` digits (default: 6) |
| `"otp"` | Exactly `otpLength` digits (default: 6) |
| `"backup_code"` | `min(1)` — no format constraint |

## Method Switching

When a user clicks an `AlternativeMethods` button, `activeView` changes, the form resets, and the schema is recreated dynamically — all without page navigation.
