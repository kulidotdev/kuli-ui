## Usage

### Email only

The simplest setup — a single email + password form.

<ComponentPreview name="signin/email-only" />

### Method switch

When `methods` has more than one value, a "Switch?" select appears inline next to the identifier label. Users switch between email, username, and phone without leaving the page. The form resets automatically on switch.

<ComponentPreview name="signin/multi-method" />

### With social providers

Pass a `providers` array to `SignIn.Social`. Each provider renders as a button in a 2-column grid.

<ComponentPreview name="signin/with-social" />

### With passwordless

`SignIn.Passwordless` renders Magic Link and/or Passkey buttons. Magic Link is automatically disabled when the active method is not `email`.

<ComponentPreview name="signin/with-passwordless" />

### Loading state

Pass `isLoading={true}` to disable all inputs and show a spinner on the submit button.

<ComponentPreview name="signin/loading" />

### Error state

Pass `apiError` to render an `AlertError` banner at the top of `SignIn.Content`.

## Props

### `<SignIn>` (Root Provider)

| Prop | Type | Default | Description |
|---|---|---|---|
| `onSubmit` | `(values: SigninFormValues) => void` | — | **Required.** Called when the form is submitted with valid values |
| `methods` | `SigninMethod[]` | `["email", "username", "phone"]` | Identifier methods to show. An empty array hides the form entirely |
| `isLoading` | `boolean` | `false` | Disables all inputs and shows a spinner |

## Types

### `SigninMethod`

```ts
type SigninMethod = 'email' | 'username' | 'phone';
```

### `SigninFormValues`

Discriminated union — narrow on `values.method`:

```ts
type SigninEmailValues    = { method: 'email';    identifier: string; password: string; remember?: boolean };
type SigninUsernameValues = { method: 'username'; identifier: string; password: string; remember?: boolean };
type SigninPhoneValues    = { method: 'phone';    identifier: string; password: string; remember?: boolean };

type SigninFormValues = SigninEmailValues | SigninUsernameValues | SigninPhoneValues;
```

```ts
const handleSubmit = async (values: SigninFormValues) => {
  if (values.method === 'email') {
    await yourAuthLibrary.signInWithEmail(values.identifier, values.password);
  } else if (values.method === 'phone') {
    await yourAuthLibrary.signInWithPhone(values.identifier, values.password);
  } else {
    await yourAuthLibrary.signInWithUsername(values.identifier, values.password);
  }
};
```

## Validation

| Method | `identifier` | `password` |
|---|---|---|
| `email` | `z.string().email()` | `z.string().min(1)` |
| `username` | `z.string().min(1)` | `z.string().min(1)` |
| `phone` | E.164 via `isValidPhoneNumber()` | `z.string().min(1)` |
