## Props

### `<ResetPassword>` (Root Provider)

| Prop | Type | Default | Description |
|---|---|---|---|
| `method` | `"email" \| "phone"` | `"email"` | Determines the flow |
| `onSubmitEmail` | `(values: ResetPasswordEmailValues) => Promise<void>` | — | Required when `method="email"` |
| `onSubmitPhone` | `(values: ResetPasswordPhoneValues) => Promise<void>` | — | Required when `method="phone"` |
| `isLoading` | `boolean` | `false` | Disables all inputs |
| `apiError` | `{ message: string; code?: string } \| null` | `null` | Server error to display |
| `children` | `ReactNode` | — | **Required.** |

### `<ResetPassword.Header>`

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `ReactNode` | `"Reset Password"` | Card title |
| `description` | `ReactNode` | `"Enter your new password below."` | Card subtitle |

### `<ResetPassword.OtpField>`

Only rendered when `method="phone"`. Displays a 6-slot `InputOTP`.

### `<ResetPasswordSuccessView>`

| Prop | Type | Description |
|---|---|---|
| `redirectTo` | `string` | **Required.** URL for the "Continue" button |

## Types

```ts
type ResetPasswordEmailValues = {
  password: string;
  confirmPassword: string;
};

type ResetPasswordPhoneValues = {
  code: string;            // 6-digit OTP
  password: string;
  confirmPassword: string;
};
```

## Validation

| Field | Rule |
|---|---|
| `code` | Exactly 6 digits (phone flow only) |
| `password` | `min(8)` |
| `confirmPassword` | Must match `password` via `z.refine()` |
