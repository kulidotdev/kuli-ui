## Usage

### Unified Auto-Responsive Layout

The fastest and recommended way to construct a storytelling section. `StorytellingContent` automatically renders a clean sequential stack on mobile devices and an in-place sticky parallax presentation on desktop screens.

### Mixed / Dynamic Layout

Using the `layout` property inside each step item, you can dynamically reverse the position of the narrative and preview card on a per-step basis. The unified layout will automatically animate the column swapping.

For maximum layout flexibility, you can assemble the subcomponents manually. This lets you insert custom headers, interactive tabs with icons, custom action buttons, or custom layout columns.

The root provider component that manages active step state, scroll progress tracking, smooth step navigation, and container dimensions.

### `<StorytellingContent>`

A unified responsive container that renders steps in a sequential vertical stack on mobile/tablet viewports (`< 1024px`) and switches to an in-place sticky parallax grid on desktop viewports (`>= 1024px`).

A header bar container placed inside `<Storytelling>`, useful for section titles, badges, action buttons, or holding `<StorytellingTabs>`. Accepts standard HTML `<div>` attributes.

Navigation tab bar that renders clickable buttons for each step with optional icons. Clicking any tab smoothly animates and scrolls to that step.

A 12-column responsive grid container that organizes `<StorytellingNarrative>` (5 columns on desktop) and `<StorytellingPreview>` (7 columns on desktop). Accepts standard HTML `<div>` attributes.

The left column content container that automatically plays exit/entry slide and fade animations whenever `activeStep` changes. Accepts standard HTML `<div>` attributes.

## Hook

### `useStorytelling()`

Hook to consume the storytelling context inside any child component of `<Storytelling>`.

<AutoTypeTable path="../src/components/ui/storytelling.tsx" name="StorytellingContextValue" />

```tsx
import { useStorytelling } from "@/components/ui/storytelling"

function CustomStepControls() {
  const { activeStep, totalSteps, nextStep, prevStep, scrollToStep } = useStorytelling()

  return (
    <div className="flex items-center gap-2">
      <button onClick={prevStep} disabled={activeStep === 0}>
        Previous
      </button>
      <span>{activeStep + 1} of {totalSteps}</span>
      <button onClick={nextStep} disabled={activeStep === totalSteps - 1}>
        Next
      </button>
    </div>
  )
}
```

## Behavior & Customization

### Scroll Runway (`scrollPerStep`)

The `scrollPerStep` prop controls how much scroll distance (in viewport heights) is allocated to each step.

- **Default (`1.3`)**: Allocates `130vh` of scroll distance per step.
- **Higher values (e.g. `1.5` - `2.0`)**: Increases scroll distance, creating a more relaxed scroll experience suitable for content-heavy steps.
- **Lower values (e.g. `1.0`)**: Produces faster step transitions with minimal scrolling.

The total sticky scroll runway height is automatically computed as:

```text
Total Height = max(2, stepCount) * max(1, scrollPerStep) * 100vh
```

### Custom Navigation & Progress

Because the `<Storytelling>` component provides a robust React context (`useStorytelling`), you are completely free to build your own custom navigation controls, progress bars, and pagination markers. The `scrollYProgress` value is particularly useful for interpolating scroll completion smoothly via Framer Motion.

### Responsive Strategy

| Viewport | Layout | Behavior |
|---|---|---|
| **Mobile / Tablet (`< 1024px`)** | Vertical Stack | All steps render sequentially in document flow. Avoids sticky trapping on touch screens. |
| **Desktop (`>= 1024px`)** | Sticky Parallax Grid | Container is pinned in viewport while scrolling drives step transitions and animations. |
