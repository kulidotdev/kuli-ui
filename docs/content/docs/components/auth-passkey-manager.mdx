## Props

### `<PasskeyManager>` (Root Provider)

| Prop | Type | Default | Description |
|---|---|---|---|
| `passkeys` | `Passkey[]` | — | **Required.** List of passkeys to display |
| `onAddPasskey` | `() => Promise<void> \| void` | — | Register a new passkey |
| `onRemovePasskey` | `(id: string) => Promise<void> \| void` | — | Delete a passkey |
| `onUpdatePasskey` | `(passkey: Passkey) => Promise<void> \| void` | — | Rename a passkey |
| `isLoading` | `boolean` | `false` | Disables `AddAction` |
| `className` | `string` | — | Additional CSS class for the container |

### `<PasskeyManager.ItemDetails>`

Renders an icon (auto-selected by `deviceType`) and the passkey name + dates.

Icon mapping:
- `phone` / `mobile` → `Smartphone`
- `mac` / `windows` / `laptop` / `desktop` → `Laptop`
- `fingerprint` / `touch` → `Fingerprint`
- Anything else → `KeyRound`

### `<PasskeyManager.ItemActions>`

Dropdown menu with Rename and Remove options. Each only appears if the corresponding callback is provided.

### `<PasskeyManager.EmptyState>`

Hidden automatically when `passkeys.length > 0`.

### `<PasskeyManager.AddAction>`

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | `"Register a new Passkey"` | Button label |

Only rendered when `onAddPasskey` is provided.

## Types

```ts
interface Passkey {
  id: string;
  name?: string;
  createdAt: Date;
  lastUsedAt?: Date;
  deviceType?: string;
}
```

## Accessibility

- Every action button has a `sr-only` label for screen readers.
- Dropdown uses Radix UI `DropdownMenu` — fully keyboard navigable.
- Loading state is managed per-item to avoid disabling the entire list.
