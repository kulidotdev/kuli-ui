## Installation

```bash tab="pnpm"
pnpm dlx shadcn@latest add REGISTRY_URL/alert-card
```

```bash tab="npm"
npx shadcn@latest add REGISTRY_URL/alert-card
```

## Usage

### Default

The default `AlertCard` provides a simple informational message.

<ComponentPreview name="alert-card/default" />

### Variants

`AlertCard` supports different visual variants based on the context of the message: `info`, `error`, `warning`, and `success`. Each variant comes with a corresponding color scheme and default icon.
